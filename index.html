DheKasir

Version 2.0

DheKasir adalah ekosistem kasir retail digital modern yang dirancang khusus untuk mempercepat transformasi digital UMKM di Indonesia.

Fitur baru v2.0: Scanner barcode redesign total — mode Kasir/SKU/Stok, live scan result card, scan history strip, manual input barcode, flash, suara & getar, ringkasan scan, tombol langsung bayar dari scanner, fitur HP sebagai Scanner yang tetap tersambung meski modal ditutup, Layar Live Pelanggan — tampilan customer display real-time ala kasir minimarket, serta Login ID untuk menyinkronkan seluruh data toko (produk, transaksi, stok, hutang) secara otomatis antara HP dan Desktop.

Kebijakan Privasi

Berlaku sejak 1 Januari 2025

1. Data Lokal: Semua data tersimpan di perangkat Anda (LocalStorage). Tidak ada data dikirim ke server tanpa persetujuan Anda.

2. Cloud (Opsional): Sinkronisasi Google Spreadsheet hanya aktif jika Anda memasukkan Google Apps Script URL sendiri.

3. Kamera: Hanya untuk scan barcode secara real-time. Tidak ada foto/rekaman yang disimpan.

4. Bluetooth: Hanya untuk printer thermal. Tidak ada data dibagikan ke pihak ketiga.

5. HP sebagai Scanner & Layar Live: Kode barcode yang dipindai dari HP dikirim lewat jaringan realtime pihak ketiga hanya berupa teks kode dan total belanja, tanpa foto atau data pribadi, lalu ditampilkan secara live di layar pelanggan maupun di layar HP.

6. Login ID & Sinkronisasi Antar Perangkat: Jika Anda mengaktifkan Login ID, seluruh data toko (produk, transaksi, stok, hutang, kategori) akan disimpan pada jaringan realtime pihak ketiga menggunakan Login ID sebagai kunci akses, agar dapat diakses dari perangkat lain dengan ID yang sama. Jangan bagikan Login ID Anda ke pihak yang tidak berkepentingan.
